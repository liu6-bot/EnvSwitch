# EnvSwitch 打包教程

> 目标：把源码打成**免安装、双击即用**的可执行文件，并发布到 GitHub Releases。
> 全程只依赖一个第三方工具：[PyInstaller](https://pyinstaller.org/)。

---

## 0. 打包前的环境检查

在项目根目录执行：

```bash
python build_exe.py --check
```

它会检查 Python、tkinter、PyInstaller 三样东西。缺什么按提示装：

| 缺什么 | 怎么补 |
| --- | --- |
| tkinter | Windows/macOS：用 [python.org](https://www.python.org/downloads/) 官方安装包重装并勾选 *tcl/tk and IDLE*<br>Ubuntu/Debian：`sudo apt install python3-tk`<br>Fedora：`sudo dnf install python3-tkinter` |
| pyinstaller | `pip install pyinstaller` |

> ⚠️ 建议**在干净的虚拟环境里打包**，避免把无关依赖打进去：
> ```bash
> python -m venv .venv
> # Windows:  .venv\Scripts\activate
> # macOS/Linux: source .venv/bin/activate
> pip install pyinstaller
> ```

## 1. 一条命令打包

```bash
python build_exe.py
```

- 产物：`dist/EnvSwitch.exe`（Windows）/ `dist/EnvSwitch`（macOS/Linux），**单文件版**
- 图标、`assets/` 资源已自动带上
- 想要启动更快、杀软误报更少的目录版：

```bash
python build_exe.py --onedir     # 产物在 dist/EnvSwitch/ 目录，压缩后分发
```

等价的底层命令（想自己控制参数时用）：

```bash
pyinstaller --noconfirm --clean EnvSwitch.spec
ENVSWITCH_ONEDIR=1 pyinstaller --noconfirm --clean EnvSwitch.spec   # 目录版
```

## 2. 各平台注意事项

### Windows

- 用 **64 位 Python** 打包，产物才能在所有 64 位系统上跑；打包机的系统版本尽量低（Win10 即可），高版本打出来的包向下兼容没有问题
- 单文件版第一次启动会解压到临时目录，慢 2~5 秒，属正常现象
- 想做成安装包（开始菜单、卸载入口）：用 [Inno Setup](https://jrsoftware.org/isinfo.php)，脚本见下文 [第 5 节](#5-可选--windows-安装包inno-setup)

### macOS

- 打包产物是 Unix 可执行文件；Intel 机器用 x86_64 Python、Apple Silicon 用 arm64 Python 打包，也可以在对应机器上各打一次
- 想要 `.app` 包 + `.dmg`：

```bash
pip install pyinstaller
pyinstaller --noconfirm --clean --windowed --name EnvSwitch \
  --icon assets/icon.png --add-data "assets:assets" main.py
# 产物 dist/EnvSwitch.app（此时是 .app bundle，因为 --windowed 在 macOS 上默认生成 bundle）
hdiutil create -volname EnvSwitch -srcfolder dist/EnvSwitch.app \
  -ov -format UDZO EnvSwitch-macOS.dmg
```

- 未签名的 app 会被 Gatekeeper 拦：右键 → 打开，或 `xattr -cr EnvSwitch.app`。正式分发建议申请 [Apple Developer ID](https://developer.apple.com/) 并 `codesign --deep --force --options runtime` + 公证

### Linux

- 必须先装 `python3-tk`，否则打出来的包启动即报 `No module named tkinter`
- 打包产物对 **glibc 版本**敏感：在越老的发行版上打包，兼容面越广。建议在 Ubuntu 20.04/22.04 容器里打：

```bash
docker run --rm -v "$PWD":/src -w /src ubuntu:22.04 bash -c "
  apt-get update && apt-get install -y python3 python3-pip python3-tk binutils &&
  python3 -m pip install pyinstaller &&
  python3 build_exe.py"
```

## 3. 用 GitHub Actions 自动打三平台包

仓库已带 [.github/workflows/build.yml](../.github/workflows/build.yml)：

- **每次 push 到 `main`**：自动构建三平台产物，在 Actions 页面可下载 artifact
- **每次打 tag（`v*`）**：自动构建并创建 GitHub Release，附上全部产物

发布流程就是：

```bash
git tag v2.0.0
git push origin v2.0.0
```

## 4. 发布前自检清单

- [ ] `python build_exe.py --check` 全绿
- [ ] 打包产物在**本机**跑一遍完整流程：扫描 → 切换 → 新终端验证 → 还原
- [ ] 打开「环境体检」，确认问题列表能出、一键修复可用（系统 PATH 修复需管理员，验证一次 UAC 流程）
- [ ] 确认 `dist/` 没有把你的私人配置打进去（工具只打源码与 `assets/`，配置运行时才生成于 `~/.envswitch/`）
- [ ] `README.md` 的下载链接、版本号对得上 `CHANGELOG.md`
- [ ] Windows 单文件版如被杀软误报，在 README 的 FAQ 里说明并附目录版下载

## 5. （可选）Windows 安装包：Inno Setup

装好 [Inno Setup](https://jrsoftware.org/isinfo.php) 后，把下面内容存成 `installer.iss`（放在项目根目录），然后 Inno Setup 打开它点 *Compile*：

```iss
[Setup]
AppName=EnvSwitch
AppVersion=2.0.0
DefaultDirName={autopf}\EnvSwitch
DefaultGroupName=EnvSwitch
UninstallDisplayIcon={app}\EnvSwitch.exe
OutputBaseFilename=EnvSwitch-Setup-2.0.0
Compression=lzma2
SolidCompression=yes

[Files]
Source: "dist\EnvSwitch\*"; DestDir: "{app}"; Flags: recursesubdirs

[Icons]
Name: "{group}\EnvSwitch"; Filename: "{app}\EnvSwitch.exe"
Name: "{autodesktop}\EnvSwitch"; Filename: "{app}\EnvSwitch.exe"; Tasks: desktop

[Tasks]
Name: desktop; Description: "创建桌面快捷方式"
```

> 用 `--onedir` 的产物作为安装包内容，体积大一点但启动快、误报少。

## 6. 常见打包问题

| 现象 | 原因与解决 |
| --- | --- |
| 启动后闪退，无报错 | 用 `console=False` 的 spec 打个 **console 版**（把 spec 里 `console=True` 临时改一下）在终端运行看报错 |
| `ModuleNotFoundError: tkinter` | 打包用的 Python 没装 tk；Linux 装 `python3-tk`，Windows/macOS 换官方安装包 |
| 打包体积很大 | 检查是否在系统 Python 里打包（带了一堆无关库）；换干净 venv；spec 里 `excludes` 已排除常用大件 |
| Windows 杀软报毒 | 用 `--onedir`；或对 exe 做代码签名 |
| macOS "无法验证开发者" | `xattr -cr EnvSwitch.app` 或右键→打开 |
| 图标没生效 | 确认 `assets/icon.ico` 存在（可运行 `python tools/make_icon.py` 重新生成） |
| 「清理系统 PATH 冲突」点了没反应 | 打包产物必须支持命令行子命令：手动执行 `EnvSwitch.exe systemfix all --quiet` 看是否报错。源码运行时会调用 `python main.py systemfix ...`，打包后则调用 exe 自身 |
